# 鉄道シミュレーター

配線図上で列車を走らせる、TypeScript / React / Canvasのシミュレーターです。

## 起動

Node.js 24以上で実行してください。

```sh
npm ci
npm run dev
```

表示されたURLをブラウザで開きます。

```sh
npm test       # 計算本体のテスト
npm run build # 型検査とdist/への本番ビルド
```

## 操作

- 「再生」で開始。停止中は「1ステップ」で0.02秒進めます。
- 自動運転は目標速度を維持し、終端手前で停車します。
- 手動運転は力行・ブレーキのスライダーで操作します。片方を操作するともう片方は解除されます。
- 時間倍率は0.5〜10倍。「リセット」は同じ配線で列車と時刻を初期化します。
- 「配線をJSON保存」でネットワークを書き出し、編集したJSONを読み込めます。保存対象は配線のみで、運転状態は含みません。

## 構成とデータ

`src/core/`はReactや描画に依存しません。`step()`が固定0.02秒で更新し、画面は実時間の差分を蓄積して呼び出します。

- Port: 線路の端点。1つのPortは1本のTrackに所属します。
- Track: 両端Port、実距離（m）、制限速度（m/s）、描画用折れ線座標。
- Junction: 状態ごとの通過可能Portペア。接続しない端点は終端です。
- Train: Track ID、offset（Track先頭からのm）、direction（1/-1）、速度、編成長、通過履歴。

`src/core/demo.ts`に配線例があります。実距離と描画上の長さは独立しています。編成の占有区間は先頭位置から走行履歴を遡って求めます。初期状態で先頭から後方に十分な線路がない場合、存在する部分だけを表示します。

## 今回の実装範囲

1編成、線路接続、簡易加減速、手動・自動運転、終端停止、占有表示、再生・停止・倍率、配線JSON入出力。

手動でも終端を超えないよう位置を制限します。制限速度は区間内の上限として適用しています。低速区間に向けた事前減速、駅停車やダイヤ、分岐器の操作、複数列車、閉塞・信号・進路設定・鎖錠は次段階です。Junctionはそれらを追加するためのデータ構造を用意しています。
