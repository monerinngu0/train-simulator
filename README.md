# 鉄道シミュレーター

配線図上で列車を運行する、TypeScript / React / Canvasのシミュレーターです。

## 起動

Node.js 24以上で実行してください。

```sh
npm ci
npm run dev
```

表示されたURLをブラウザで開きます。

```sh
npm test       # 計算本体のテスト
npm run build # 型検査とdist/への本番ビルド
```

## 運転

- 「再生」で開始。停止中は「1ステップ」で0.02秒進めます。倍率は0.5〜10倍です。
- 初期の列車01は中央駅・東駅・中央駅・西駅を繰り返し運転し、東西の駅で折り返します。
- 自動運転は停車駅・制限速度・閉塞の停止位置を先読みして減速します。
- 手動運転は力行・ブレーキを操作します。手動でも閉塞への進入を防ぎます。停止後は「停止中に折返す」で前後を入れ替えられます。
- 「操作する列車」で対象を選びます。空いている線路と配置方向を選んで列車を追加できます。選択列車は黄色、他列車は紫色です。
- 列車の削除は停止・進路解放後に行います。最低1編成は残します。
- 「リセット」は最初の編成の停車計画を引き継ぎ、1編成・時刻0の状態に戻します。

## 分岐器・閉塞・進路

- J1・J2の丸印または本線／待避線ボタンで開通方向を切り替えます。両方を待避線にするとA → D → Cを通ります。
- 緑は開通方向、黄色は選択列車の占有範囲。「現在の経路」は分岐器の状態から求めた経路です。
- 1本のTrackを1閉塞として扱い、編成の後部が抜けるまで他列車の進入を禁止します。信号は選択列車から見た次の閉塞の占有・予約に応じて赤／緑を表示します。終端も赤になります。
- 列車が分岐器の各接続脚の15 m以内にある間は切替できません。
- 進路ボタンは分岐器を一括設定し、経由線路と分岐器をその列車用に予約・鎖錠します。占有・予約競合があれば変更全体を拒否します。
- 最後の線路に編成全体が入ると進路を解放します。取消は始点線路上で停止し、まだ進入していない場合に限ります。
- 中央駅の停車計画を持つ列車を待避線へ通すと、その停車駅には到達できません。待避線の駅を指定するなど、ダイヤと経路を合わせてください。

## 駅・ダイヤ

「停車駅・ダイヤを編集」を開き、停車駅を順に追加します。

- 停車時間は到着からの最小停車秒数です。
- 到着・発車予定は「適用」からの秒数。空欄なら時刻の指定はありません。
- 発車は最小停車時間と発車予定の両方を満たした後になります。
- 到着時に予定時刻との差を遅れとして表示します。
- 「折返し」で、停車扱い終了後に編成の前後を入れ替えます。線路をまたぐ編成も占有範囲を保ちます。
- 繰返し時は最後の停車扱い終了を次の周回の時刻0とします。最後の折返し後に最初の停車駅へ到達できる順序にしてください。
- 手動運転では停車位置へのブレーキ操作を自分で行います。指定位置で停止すれば停車扱いに入ります。

## 配線編集・JSON

停止して「配線を編集」を開きます。

1. 「線路を描く」を選び、図上の始点と終点をクリックします。
2. 線路をクリックまたは一覧から選び、実距離と制限速度を編集します。
3. 接続に使う端点を選びます。共通・本線の2端点なら単純接続、待避線側も選べば分岐器になります。
4. 選択線路の停車位置と駅名を入力して駅を追加します。
5. 進路名、経由線路、各分岐器の状態を指定して進路を追加できます。
6. 「この配線を適用」で運転を初期化します。閉じれば編集を破棄します。

線路の削除時は関連する駅・接続と進路定義を取り除きます。駅・接続・進路も個別に削除できます。

「配線をJSON保存」で線路・接続・駅・進路を保存します。保存対象は配線のみで、列車・ダイヤ・運転中の状態は含みません。既存の駅・進路を含まないJSONも読み込めます。読込・配線適用後は停車計画を設定してください。

## 構成

`src/core/`はReact・描画非依存です。`step()`を固定0.02秒刻みで呼び、画面側で実時間差分を蓄積します。

- Port: 線路端点。1つのPortは1本のTrackに所属。
- Track: 両端Port、長さ（m）、制限速度（m/s）、描画用折れ線。実距離と描画距離は独立。
- Junction: 状態ごとの通過可能Portペア。
- Station: 駅名、Track ID、停車位置。物理線路から独立。
- Route: 経由線路と分岐器の状態。予約・鎖錠はSimulationで管理。
- Train: ID、先頭のTrack ID・offset・direction、速度、編成長、通過履歴、停車計画。

データ例は`src/core/demo.ts`にあります。

## モデルの範囲

閉塞は線路単位の保守的な方式です。同じTrackに複数列車は配置できません。分岐器の進路鎖錠はありますが、実鉄道の接近鎖錠・時素解錠・多現示信号・ATS/ATC全体を再現するものではありません。自由な分岐器操作で接近中の経路を変えた場合など、制動距離が不足すると境界で速度・位置を制限します。

自動で進路を設定する指令機能やデッドロック解消はありません。複数列車を運行する場合は、停車計画・進路・発車時刻を調整してください。
